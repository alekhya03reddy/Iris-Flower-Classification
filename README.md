#CodSoft

This project classifies Iris flowers into different species using Machine Learning techniques.

## Objective
To build a classification model that predicts Iris flower species based on sepal and petal measurements.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
- K-Nearest Neighbors (KNN)

## Features Used
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Accuracy
Approximately 100%

## Dataset
Iris Flower Dataset from Kaggle

## Conclusion
Successfully built an Iris Flower Classification model using KNN with high prediction accuracy.
